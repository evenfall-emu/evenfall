# Sunset assets

`coast.png` is a 1672 × 941 painting of the sea, cliffs, a lighthouse and a
distant castle at sunset. The shared header's banner is a crop of it. It is
original artwork made for the player with an image-generation tool and finished by
hand on the pixel grid; it contains no ROM data or game sprites.

In text the project is described as "Evenfall", never with a platform
holder's brand.
