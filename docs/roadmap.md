# Roadmap

- Color effects use exact scalar lanes; evaluate stable-Rust SIMD alternatives against the per-dot reference and measure before replacing the hot path.
- Compressed rewind entries differ byte-wise from ZiGBA's while remaining mutually decodable; measure miniz_oxide level 1 against Zig `level_1` on representative ~0.5 MB states for compression ratio and encoding speed.
- Selective-video recovery writes a portable state at each anchor and loads it into a new scratch machine before replay, rather than copying a raw preallocated machine. This adds a full encode per rebase and a validated decode plus heap/media construction per reconstruction. A safe allocation-free raw copy needs an audited `clone_into` for the Bus's independent boxed RAM, video caches, save medium and owned ROM/BIOS, and must not copy its transient external-input pointer. Keep the portable path as a correctness reference if a raw copy is added; compare exact pixels and machine state and measure the difference first.
- The Bus copies ROM and BIOS at machine construction even for immutable media. Guest behavior and media binding match ZiGBA's immutable-media mode, but construction uses additional memory and a copy proportional to media size; revisit only if measured costs justify shared immutable ownership without aliasing mutable media.
- `Machine::write_state` buffers its bounded payload before writing to the caller's `Write`, unlike ZiGBA's direct streaming writer. The bytes are identical, but this adds a payload allocation and copy; consider a writer-backed codec sink if streaming cost matters.
